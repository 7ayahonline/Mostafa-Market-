# المصطفى — نسخة GitHub Pages جاهزة

ارفع **كل الملفات الموجودة في هذا المجلد** إلى جذر مستودع `Mostafa-Market` على فرع `main`.

## إعداد GitHub Pages

Settings → Pages → Build and deployment:
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/(root)`

بعد الحفظ افتح:

https://7ayahonline.github.io/Mostafa-Market/

## مهم

- اسم الصفحة الرئيسية يجب أن يكون `index.html` بالضبط.
- `manifest.json` و`sw.js` وملفات الأيقونات مطلوبة لتحسين PWA والعمل دون اتصال جزئيًا.
- المتجر الحالي واجهة Front-end تعمل على GitHub Pages، والسلة والمفضلة والطلبات تحفظ محليًا في المتصفح.
- الدفع الحقيقي، قاعدة البيانات، الحسابات، المخزون المتزامن، والإشعارات تحتاج Backend/خدمة خارجية؛ لا يتم اختراع هذه الخدمات داخل GitHub Pages.
